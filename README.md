One original line of plain text: a review of planet Earth left by an alien tourist, at most 200 characters.

## Entry

> Earth: the locals worship small furry landlords who sleep 16 hours a day, accept rent in food, and never say thanks. 5/5 stars, would serve again.

## Run

```sh
node main.ts
```

`main.ts` (Node stdlib only) reads `entry.txt`, validates it is 1–200 characters of non-whitespace text, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
